這個專案是用來展示「Bootstrap 5 + SCSS + BEM + SSG（Eleventy）」的多頁式網站結構， 方便你在投遞案件時，直接附上 GitHub 與 Demo 連結，證明你有完整全站切版的實作能力。

你可以在表單上這樣描述這個作品：
「以 Eleventy 建立 Bootstrap 5 RWD 全站切版範本，使用 SCSS 變數客製主題色與元件風格， 採 BEM 命名規範，包含首頁、服務、關於與聯絡等多頁式結構。」

專案技術摘要

  • HTML5 / CSS3 / SCSS
  • Bootstrap 5（自訂變數編譯）
  • BEM 命名、RWD 版面
  • Eleventy 靜態網站產生器
  • Node 20 / Yarn
